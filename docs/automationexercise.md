# AutomationExercise Scraper

input: https://automationexercise.com/

This feature adds a basic web scraper for https://automationexercise.com/.

## Usage
- Run `src/automationexercise_scraper.py` to fetch and print product categories from the homepage.

## Implementation
- Uses `requests` and `BeautifulSoup` to fetch and parse categories.
- See `src/automationexercise_scraper.py` for details.
